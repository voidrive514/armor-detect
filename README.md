# 传统视觉装甲板识别（静态图片）

C++ / OpenCV 程序：输入一张前哨站图片，自动完成颜色分割、灯条候选提取、灯条配对，输出装甲板的外接框、中心点和有序四角点。

## 1. 目录结构

```text
项目根目录/
├── CMakeLists.txt
├── 源1.cpp                  
├── README.md
├── images/
│   └── outpost_frame.png     （指定输入图片，1280×1024，3 通道）
└── output/                   （程序自动创建）
    ├── mask.png              原始颜色 mask
    ├── cleanMask.png         闭运算后的 mask
    ├── candidates.png        灯条候选图
    └── result.png            最终装甲板结果图
```

## 2. 编译与运行

在项目根目录执行：

```text
cmake -S . -B build -DOpenCV_DIR="<OpenCV 中 OpenCVConfig.cmake 所在的文件夹>
cmake --build build --config Debug"
cmake --build build --config Debug
```

**请在项目根目录下运行**，因为图片使用相对路径读取：

```text
build/Debug/armor_detect.exe images/outpost_frame.png
```

- 不带参数时，默认读取 `images/outpost_frame.png`（默认路径集中定义在代码开头的 `DEFAULT_IMAGE`）。
- 图片读取失败、结果保存失败时，程序会输出提示并返回 -1，不会继续处理空图像。
- 没有检测到装甲板时，程序输出“未检测到装甲板”并正常返回 0。

## 3. 终端输出内容

程序启动时输出图片宽、高、通道数；对每个装甲板输出：颜色、左右灯条编号、中心点、外接框（x, y, 宽, 高）、四个角点坐标、是否有效。

## 4. 方法说明

### 4.1 颜色分割

图中目标灯条为红橙色，背景中有白色过曝光源和零星亮点。使用两个条件取交集：

1. **HSV 范围**：红色色相跨过 0，所以用 0–12 和 165–180 两段 `inRange` 后合并；饱和度下限 100 用来排除白色光源，亮度下限 120 用来排除暗处噪点。
2. **红蓝通道差**：`R − B > 60`。白色、灰色背景的红蓝值接近，差值很小；红色灯条的红明显大于蓝。

只用 HSV 时背景中会混入较多杂物；加上红蓝差并取交集后，杂点明显减少。随后用 10×50 的矩形结构元做**闭运算**，补上灯条中心过曝形成的空洞和缺口。

### 4.2 灯条筛选

对 mask 用 `findContours`（`RETR_EXTERNAL`，只取最外层轮廓），每个轮廓用 `minAreaRect` 得到旋转矩形，保留满足下列条件的：

- 面积 ≥ 20；
- 长宽比（长边/短边）≥ 3，即细长；
- 每根灯条保存：颜色、旋转矩形、长、宽、与竖直方向的夹角。

（以上数值以代码开头的参数为准。）

### 4.3 灯条配对

对任意两根灯条检查，全部满足才算一对：

- 颜色一致；
- 长度比（短/长）≥ 0.7；
- 倾角差 ≤ 15°；
- 两中心竖直偏差 / 平均长度 ≤ 0.5；
- 两中心距离 / 平均长度在 1.5～4.0 之间。

所有条件都用相对比例表达，目标远近变化时依然适用。配对后再检查装甲板外接框的 宽/高 是否在 1.2～5.0，并对外接框重叠超过一半的结果去重（保留先出现的）。每个装甲板记录对应的左右灯条编号。

### 4.4 中心点、外接框与四角点顺序

- 外接框：四个角点的 `boundingRect`；
- 中心点：四个角点的平均位置；
- 角点：先按中心 x 坐标区分左、右灯条；每根灯条的 4 个顶点按 y 排序，上面两点取中点作为上端点，下面两点取中点作为下端点。

**四角点顺序约定（图像坐标系，顺时针）：**

```text
0 = 左灯条上端点（左上）
1 = 右灯条上端点（右上）
2 = 右灯条下端点（右下）
3 = 左灯条下端点（左下）
```

结果图中角点旁标有 0、1、2、3 用于检查顺序。该顺序作为后续 `solvePnP` 的输入约定。

## 5. 单帧检测接口

```cpp
vector<Armor> detectArmors(const cv::Mat& image, DebugInfo* debug = nullptr);
```

输入一张三通道彩图，返回装甲板列表；传入 `DebugInfo` 指针时额外返回 mask、闭运算后 mask 和灯条候选图。函数内部不读写文件，也不含任何写死的目标坐标，后续可以直接逐帧调用。

## 6. 问题记录


### 问题 1：mask 中杂物太多、灯条是空心的

- **出现的步骤**：颜色 mask 生成与轮廓提取。
- **现象**：只用 HSV 提取时，目标灯条之外还提取出很多杂物；灯条中心过曝发白，被排除，mask 里只剩外圈，呈 J、U 形的空心轮廓。
- **修改**：HSV 增加饱和度、亮度下限，并与红蓝差 mask 取交集；用竖直方向较长的结构元做闭运算；轮廓提取使用 `RETR_EXTERNAL`，让空心的环也被当成一个整体。
- **结果**：候选灯条收敛为两根，终端输出：候选面积分别约 173.5 和 186，长均为 33，宽分别为 9 和 7，中心约 (545.5, 719.5) 和 (622.5, 711.5)。


### 问题 2：函数参数没有用引用，角点没有带出来

- **出现的步骤**：生成装甲板、求灯条上下端点时。
- **现象**：结果图上没有画出装甲板框。
- **原因**：`BarEnds` 的 `top`、`bottom` 参数按值传递，函数里改的是副本，外面的四个端点变量没有被赋值，后面算出的角点和外接框是未初始化的垃圾值。
- **修改**：把参数改成引用 `cv::Point2f&`。
- **结果**：角点坐标正确，结果图上 0、1、2、3 分别位于左上、右上、右下、左下，外接框和中心点位置正确。
